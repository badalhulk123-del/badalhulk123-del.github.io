# Badal Rajput — Portfolio

A responsive, single-page portfolio website built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a GitHub repository (for example `badal-portfolio`).
2. Upload the **contents** of this folder, keeping the `assets` folder structure intact.
3. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.
4. GitHub will provide your public portfolio URL.

The PDF/image buttons are relative links, so they will continue to open the bundled documents after deployment.
